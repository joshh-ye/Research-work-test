## 0. One-command CPU clean-room check
```
bash scripts/reproduce_cpu.sh [--with-provenance] [--skip-e2] [--skip-extended] [--scratch DIR]    # ~9 min on 4 threads (2026-10-20); CPU only
```
**Scope: the clean room re-runs the same code from the same saved intermediates on the same host (same venv, same filesystem); it is a bit-identical re-computation check, not an independent-environment reproduction.** Figure/data CSV `source` columns hold absolute host paths (`/home/yejz1/...`) and are ignored in the comparison. Re-runs, from saved intermediates, into a scratch tree (default `/nobackup/user/yejz1/crc_phase2/cleanroom`, ~52 MB; home quota is near its limit, see section 3b): exposure-stratified stats (EXP-006), E7 analyze for Enformer/AlphaGenome (EXP-010, saved per-tile npz), E2 labels + power, E2 interim AlphaGenome and Enformer (single-model `--unblind --models <m>` runs), **E2 final 4-model run (EXP-017)**, **`06_summaries.py` (E4/E5 summary tables, EXP-013/015)**, **`07_e4_sensitivity.py --part A` (EXP-014 cluster CIs)**, **`model_concordance.py` (EXP-012)**, **figures 1-6 + supplementary tables**, and optionally the E1 provenance build. Code is copied into the scratch tree with the repo-root path rewritten (sed) and inputs are symlinked read-only, so no script's default output directory changed and recorded outputs are never overwritten (`PD_RESULTS` points `06_summaries.py` at scratch). `scripts/compare_outputs.py` then diffs every numeric cell (rtol 1e-6, atol 1e-9; non-numeric cells exact) plus named key numbers; figure CSV `source` columns (absolute input paths) are ignored and rendered PNGs are only checked for existence (PDF/PNG bytes embed metadata).
Not re-run by the script (need the 160 GB trunk cache, GPU, network or a different venv): `07_e4_sensitivity.py --part B/C/D/Cr/S` (parity, exposure-controlled ridge/Gram, fold stratification), `01_build_cache`, `02_train_head`, `03_ridge`, `04_pretrained_valsel`, `05_e8` (E8 outputs are therefore not re-derived), EXP-018 `post_final_exploratory.py`, variant scoring, the AlphaGenome cache builds (ag-venv).
Result of the 2026-10-20 extended run (log in `/nobackup/user/yejz1/crc_phase2/cleanroom/compare_report_final.txt`): **92 table/JSON/npz/figure-file checks and 24 key numbers, 0 failures; every numeric cell has max|diff| = 0 (bit-identical)**. ## 3b. Storage, hardware and the BL-008 lesson
- Check `accre_storage` before any large run. On 2026-10-20: home 174 GB used of a 186 GB quota (232.8 GB hard limit), `/nobackup/user/yejz1` 160.5 GB used of 186 GB. BL-008 (2026-10-20 ~03:15): the trunk cache hit the home hard limit (52 GB written of a planned ~330 GB), which killed the Borzoi scoring job (4/20 chunks saved) and the cache build. Fix: **put caches and large outputs on `/nobackup/user/yejz1/crc_phase2/` and symlink them into `results_phase2/`** (`trunk_cache`, `e7_nonoracle` are symlinks), keep the cache design within budget (SD-018 slim cache, 160.5 GB), and give long jobs a quota guard (`01_build_cache.py` exits 3).

## 6. Known non-reproducibility / limitations
- Borzoi-TL training: no seed, 7-day GPU job; reproduction means re-evaluating the saved checkpoint, not retraining (E5 cache-retrained seeds address this).
- Enformer/AlphaGenome August runs: producing logs missing; EXP-010 re-run reproduces the oracle mean r to 1e-7 (e7 summary.json).
- AlphaGenome hosted API: model version not exposed; scores may drift if the API model is updated.
- hg38 FASTA and bigwig bulk-download provenance UNRECORDED (see table 1).
- `scripts/reproduce_cpu.sh` starts from saved per-tile sufficient statistics/score caches; it does not re-run GPU inference, the 160 GB cache build, ridge/Gram fits, E8, `post_final_exploratory.py`, or network fetches (see section 0).
- The E4/E5 head trainings and all caches are not archived in git; E5 seeds quantify head-training variance but do not make EXP-001 bit-reproducible.
- `reproduce_cpu.sh` exercises the E2 final unblinded analysis only into a scratch directory and never writes `results_phase2/e2_validation/final/` (a pre-registered record).
