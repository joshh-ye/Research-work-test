# Fine-tuning validation audit (EXP-019 locked result)
Audit date 2026-10-26 (19:10–19:40 CDT). Auditor: Opus coordinator session; independent review is recorded in `research_management/REVIEW_FINDINGS.md` (RV-FT-04).
Scope: verifies the reported result **8-member fine-tuned Borzoi ensemble, test mean Pearson r 0.7578 vs E4 ridge 0.7406 on 152 tracks (Δ +0.0173), 145/152 tracks improved, chr9+chr22**.
Primary records checked: `analysis/ft/{train_ft,model_ft,predict_ft,compare_ft,data_ft}.py`, `results_ft/runs/<RUN>/{run_cmd.json,best_model.pt,stdout.log}`,
`results_ft/ft_test_eval/*/run_info.json`, `research_management/finetuning/{FT_PLAN.md,LOCK_PROPOSAL.md,TEST_LOCK.csv,final/*}`, git history.

**Verdict: the reported numbers reproduce from the records. No train/test or validation/test leakage was found. One preprocessing asymmetry (test-time reverse-complement averaging applies to the fine-tuned models but not to the ridge) and three interpretation caveats (comparator choice, known comparator test score, pretrained-model exposure) are real. All of them were already disclosed; none changes the claim as worded in manuscript v2. The 2-chromosome test set limits how far the result generalizes.**

## 2. Leakage checks

| Risk | Finding |
|---|---|
| Training/test leakage (regions) | None. The splits are chromosome-disjoint and asserted in code. Tiles do not overlap within or across splits. |
| Validation/test leakage | None found. Checkpoint, TTA, ensemble membership and blend weight were all chosen on validation. The lock was committed before the first test run, with one evaluation per config. The bootstrap seed and CI schemes are inherited from E4, not chosen per result. |
| Accidental reuse of held-out targets | None found. Training reads `split == "train"` gids only. Test targets are read only inside the locked evaluation paths (`predict_ft.do_test*`, `test_eval_cache.py`) and, after 2026-10-26, the ablation path gated by `ABLATION_LOCK.csv` (commit 9aa33aa). |
| Test-set-based ensemble selection | No, for the primary. The 8-member ensemble was locked on validation r. The near-tied alternatives (4-replicate partial 0.7475, LoRA-only 0.7477) are disclosed. The ablation in `ENSEMBLE_ABLATION.md` selects its subsets on validation, and its test numbers are post hoc and descriptive. |
| Inconsistent preprocessing (baseline vs FT) | Same tiles, targets, crop, pool and grid (asserted). Two disclosed differences remain. (a) RC test-time averaging is applied to FT and not to the ridge; locked row 2 (FT without TTA) gives Δ +0.0121, TF-cluster [0.0072, 0.0196], two-way [0.0007, 0.0238], so about 0.005 of the gain is attributable to TTA. (b) FT members read sequence with true shift ± 4 bins + RC training augmentation; the ridge reads 4-replicate pretrained outputs (shift-emulated cache, no RC). The comparison is therefore *system vs system*. |
| Comparator knowledge | The E4 ridge test score (0.7426 / 0.7406) was public before the FT program, and FT design choices were made knowing the target to beat. Selection never used test data, but this is a soft researcher degree of freedom; ~120 validation-evaluated configurations preceded the lock. |
| Comparator strength | E4 ridge is the pre-specified comparator, not the strongest linear readout. FT-C61 (a better cache ridge, locked secondary) scores 0.7466 on 152; the primary exceeds it by ≈ +0.011 (difference of two locked results, no CI computed). |
| Pretrained-model exposure | About 44% of test bp lie in Borzoi training folds, and the pretrained trunk has seen these sequences with other targets. This affects both systems; the direction of bias in Δ is unknown. Using the 152 non-identical tracks removes the 31 identical experiments; tracks in the same cell line and with the same target remain (`track_exposure.tsv`). |

## 3. Serious methodological issues
None that require changing the interpretation beyond what manuscript v2 (a4e0d12) already states. The points the manuscript must keep, all present in v2 §2.8c / §3.7.5 / Discussion 3a / Limitations 23–27, are:
1. Attribute the gain to the locked system (trunk adaptation + 8-member ensemble + RC TTA). Frozen-feature MLP heads also beat the ridge on validation (FT-C83 0.7378, FT-C84 0.7404), so trunk adaptation is not shown to be necessary.
2. State that the result is conditional on two test chromosomes (359 tiles). The TF-cluster CI conditions on these regions; the tile-block and two-way CIs partly address region variation.
3. Report the exact Δ as +0.0173 (unrounded 0.01728). The value +0.0172 is the difference of the rounded means (0.7578 − 0.7406).

## 4. Not verified / out of scope
- Bit-level reproducibility of training. Training used bf16 and non-deterministic kernels; checkpoints are retained, so inference is reproducible.
- Generalisation beyond chr9/chr22 and to variant-effect prediction (MPRA not used; BL-007 open).
