# Post hoc biological analysis of the locked fine-tuning test result

Status: post hoc, descriptive, exploratory. Nothing here changes the locked result. Script: `analysis/ft/bio_analysis.py`
(one command: `CUDA_VISIBLE_DEVICES= ./torch-venv/bin/python analysis/ft/bio_analysis.py`). Tables: `reports/ft_bio/`. Figures: `figures_ft_sprint/` (+ `data/` CSVs).

## 1. Methods (exact)
- Locked comparison: 8-member fine-tuned Borzoi ensemble with RC averaging (`r_FT-T01_PRIMARY_ENS8_rc`) vs E4 ridge on pretrained Borzoi outputs (`ridge[pre_raw:union1888]`), from `research_management/finetuning/final/per_track_test_r.csv`. hg38, test chr9+chr22, 359 tiles x 896 x 128 bp; per-track **Pearson r** pooled over all test bins (not r^2, not prediction R^2).
- Claim set = 152 tracks with Borzoi_class != identical_experiment; all-183 repeated and labelled `all183`. The two sets are never pooled as one claim.
- Baselines: Borzoi-TL (frozen-trunk MLP head), linear probe on frozen trunk embedding (trunk1920), pretrained Borzoi track chosen on validation (valsel). Per-track r = Pearson over sums of per-tile sufficient statistics across all tiles (`cmp_lib.metrics`). The ridge r recomputed from stats matches the CSV (max abs diff 1e-16). Paths: `TL_PATHS` of `analysis/priorityD/07_e4_sensitivity.py`.
- Delta = r_FT - r_ridge; relative delta = delta/(1 - r_ridge) (fraction of headroom closed; also delta/r_ridge in the table).
- Signal metrics from TEST targets only (`/tmp/yejz1_ft/pooled128/test_tgt.npy`, 321,664 bins/track, no negative values): mean; CV = SD/mean; fraction of bins >0; fraction of total signal in the top 1% of bins (3,217 bins). Baseline ridge r = headroom.
- Categories use only `exposure_audit/track_exposure.tsv` columns: TF label groups (analyst's grouping: POLR2A; "architectural / cohesin-CTCF" = CTCF, RAD21, SMC1A, SMC3, NIPBL; other; and the simpler POLR2A/CTCF/RAD21/other), cell line, Borzoi_class, data source (ENCSR present vs GSM only), quartiles of each signal metric and of ridge r. "Non-TF ChIP" classification is minimal: POLR2A = RNA polymerase, H2AZ = histone variant (1 track, HCT-116, GSM-based); every other label is left "TF/chromatin-associated (unclassified)" (it includes e.g. EP300, BRD4, KAT7, OGT, which were not reclassified).
- CIs: 95% percentile bootstrap over TF clusters within the category, 10,000 resamples, seed 20261020 (clusters resampled with replacement, pooled mean of per-track deltas). Categories with fewer than 8 TF clusters have no cluster CI (NaN; a percentile cluster bootstrap over 1-7 clusters is not meaningful; RV-FT-04); a track-level bootstrap CI is given only as a reference column (`ci95_track_*`) and treats tracks as independent, which they are not.
- Spearman (delta and relative delta vs 5 continuous variables) at track level and TF-aggregated (mean per TF, 62 clusters in 152 set); Benjamini-Hochberg within each track set across its 20 tests (2 levels x 2 outcomes x 5 variables; `q_BH_within_set_all_levels`).

## 3. Cautious interpretation (hypotheses, not findings)
- H1: Pretrained Borzoi outputs carry less usable information for factors/cell types poorly represented in its training tracks (lower ridge r, more tissue-restricted factors such as GATA6/HNF4A/FOXA2 in Caco-2/LS174T/LS180), so adapting the trunk helps most there. Consistent with the headroom correlation, but confounded by baseline r and unable to separate cell line from factor. Moreover delta = r_FT - r_ridge contains -r_ridge, so its negative correlation with r_ridge (and the lowest-quartile effect) is partly mathematical coupling / regression to the mean and is not by itself evidence for H1.
- H2: Broadly bound, abundant signal (POLR2A; CTCF/cohesin) is already well captured, leaving little headroom; sparser/higher-CV tracks gain more. Alternative: a ceiling set by replicate noise (not measured here).
- H3: The small ENCSR-present gain may reflect more of these experiments being well-represented/exposed (ridge r higher: 0.79) rather than data source per se.
None of these was tested prospectively.

## 4. Limitations
Post hoc and exploratory; two test chromosomes (chr9, chr22) which are largely in Borzoi/Enformer training folds; tracks within a TF, cell line and study are not independent (TF-aggregated Spearman and TF-cluster CIs partially address this; single-TF and single-track categories have no valid cluster CI); BH is applied only within the 20 Spearman tests per track set, not across the many category comparisons (which are descriptive and uncorrected); exposure to Borzoi training (112 of 152 are same_cellline_other_target) is not removed; delta CIs condition on the test regions; the TF-group classification is the analyst's and minimal (no pathway or family labels); a few outlier tracks (GATA6 Caco-2 362, ZFX, CTCF 85286) dominate means in small categories (use medians); relative delta is unstable for low-r tracks; replicate-level noise ceilings are unknown.
